# Architecture overview

MACROX RouteDeck is a Wails v3 desktop shell around a Go core. React renders state. Go decides policy and talks to ProxyBridge.

```text
Wails v3 / React
       |
Wails inbound services (DTO, events)
       |
Application services (use cases)
       |
Domain (entities, invariants)
       |
Ports
       |
Adapters:
  ProxyBridge CLI
  macOS Keychain
  GORM + SQLite
  macOS discovery
  process control
```

## Dependency direction

Dependencies point inward. Domain does not import adapters. Application does not import GORM or Wails. Adapters implement ports defined by application or domain packages.

Composition starts in `main` (Wails entry). When services grow, wiring moves to `internal/bootstrap`. Do not create that package until a READY task needs it.

## Runtime truth

| Question | Answer |
| --- | --- |
| Who stores user config? | Go, via the persistence adapter |
| Who shows state? | React, from a snapshot |
| Who moves packets? | Official ProxyBridge CLI |
| Who holds passwords? | macOS Keychain |

## v1 platform

macOS 13+ desktop. Other OS trees generated by `wails3 init` are not product targets.
