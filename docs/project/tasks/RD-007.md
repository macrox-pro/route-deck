# RD-007: CI baseline workflow

Status: REVIEW
Priority: P2
Owner: agent
Reviewer: owner

## Goal

Add a GitHub Actions workflow that matches local checks. Do not require ESLint.

## Context

`.golangci.yml` exists. Frontend check is `tsc` via Vite scripts in `frontend/package.json`. ADR-0005 and `docs/operations/development.md` name the commands. Owner asked for the workflow file (plan stage 2).

## Current behavior

No `.github/workflows/` file exists.

## Desired behavior

`.github/workflows/ci.yml` runs on push and pull_request on `macos-latest` with CGO: `go test ./...`, `golangci-lint run ./...` at v2.15.0, and `npm run build` in `frontend/` after `npm ci`. No ESLint. No `keychain_integration` tag. Vendor mode stays on.

- Non-blocking: RD-033 / RD-037 / RD-038 stay REVIEW for owner smoke

- Update STATUS, BACKLOG, HANDOFF

- [ ] `.github/workflows/ci.yml` exists with push and pull_request triggers
- [ ] Jobs run `go test ./...`, `golangci-lint run ./...` (v2.15.0), and `npm run build` in `frontend/`
- [ ] No ESLint step
- [ ] No `keychain_integration` tag
