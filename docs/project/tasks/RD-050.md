# RD-050: Nested helper discovery (Resources, Current, IsUpdater)

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Expand the macOS ApplicationInspector so every nested `.app` with an executable is found once (including Resources), paths prefer `Versions/Current`, Sparkle helpers set `IsUpdater`, and duplicates from symlinks are dropped.

## Context

ADR-0014. ChatGPT nests Codex helpers under Frameworks and Resources. Current walk misses Resources; Sparkle Updater appears twice; versioned paths break after updates.

## Current behavior

Walks Frameworks/Helpers recursively for `.app` only. No Resources. No EvalSymlinks dedupe. No IsUpdater. Paths keep `Versions/157...`.

## Desired behavior

- Every nested `.app` with CFBundleExecutable, including under Resources
- Dedupe by EvalSymlinks real path
- Prefer `Versions/Current` in stored Path
- IsUpdater true for Sparkle-style helpers
- No `.xpc` / `.appex`

## Scope

- `internal/application/port` InspectedProcess fields
- `internal/adapter/outbound/macos/inspector.go` + fixtures/tests
- STATUS / BACKLOG / HANDOFF

## Out of scope

- Confirm sync, dialogs, Dock, agent commit

## Acceptance criteria

- [ ] ChatGPT-shaped fixture finds Codex helper, renderer, alerts, CodexCLI, Computer Use once each; Sparkle once with IsUpdater
- [ ] Paths use Versions/Current when present
- [ ] `go test ./internal/adapter/outbound/macos/` PASS
- [ ] `golangci-lint run ./...` PASS

## Constraints

- MUST follow AGENTS.md and ADR-0014 Closed rules
- MUST NOT put `.app`/plist strings outside macos adapter
- MUST NOT invent Wails/GORM APIs
- MUST NOT `git commit`
- No `.xpc`/`.appex`
