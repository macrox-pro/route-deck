# RD-038: Activity JSON log viewer

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Show recent RouteDeck JSON log records on the Activity screen without passwords or a connection journal.

## Context

ADR-0011. CONCEPTION Activity v1 is RouteDeck events and health. The Activity page is a placeholder. The rotating JSON log already exists under `logfile.DefaultPath`.

## Current behavior

`frontend/src/pages/activity.tsx` shows an empty state that says events land in a later task. No Wails activity API exists.

## Desired behavior

`ActivityService.Recent(before)` returns up to 100 records and `hasMore`. Empty `before` is the newest page; a non-empty exclusive RFC3339 cursor loads older records. The Activity page lists them with empty/error states, Refresh (reset), and Load more (append). Product events trigger a reload; they are not proof of `Active`.
