## Goal

Tray Status and tooltip track ProtectionState (and BridgeState when not Ready); Stop enables only when RouteDeck owns the CLI; Quit dialog states that protection will stop when CLI is owned, then Stop and quit.

## Context

ADR-0010. RD-035 tray shell. CLI owned ≡ `BridgeState` in `Ready`, `Starting`, `Stopping`. `Conflict` is not owned.

## Current behavior

Static Status; Stop always disabled; Quit dialog has no CLI-owned copy.

## Desired behavior

Status/tooltip from snapshot + bridge. Menu refresh on `protection.state.changed` / `proxybridge.state.changed` and initial snapshot. Stop enabled only when CLI owned. Same Quit dialog for tray, Cmd+Q, Dock Quit. Hidden-window Show-then-dialog when needed. Table-driven tests for status label and CLI-owned helpers.
