# RD-059: Appearance setting + native window frame sync

Status: REVIEW
Priority: P2
Owner: agent
Reviewer: owner

## Goal

Persist Appearance (`system` | `light` | `dark`, default `system`) in SQLite and keep the native window frame in sync by recreating windows with verified Wails create-time theme options.

## Context

Owner decisions: SQLite storage; recreate main on change; close editors first; dirty → Discard (Cancel aborts, no save); do not reopen editors. Wails v3.0.0 has no public runtime SetAppearance (vendor-verified). Frontend passes `location.hash` for main URL restore.

## Current behavior

CSS theme via ThemeProvider + localStorage. Main window uses white BackgroundColour and no Mac.Appearance. Go Settings has no appearance field.

## Desired behavior

- SQLite SoT for appearance; empty/missing → system
- Settings Select → SetAppearance(appearance, mainHash) → persist → recreate main
- Main + editor windows use Mac.Appearance / Windows.Theme mapping
- No white BackgroundColour override
- localStorage is FOUC write-through of SQLite only

- Non-blocking: RD-058 REVIEW
