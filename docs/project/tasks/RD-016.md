# RD-016: Replace Wails greet template with SnapshotService

Status: DONE
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Remove GreetService and the time event; wire sqlite and SnapshotService so the app returns a snapshot DTO.

## Context

Depends on RD-015. Window still terminates when last window closes (tray later).

## Current behavior

`main.go` registers GreetService and emits `time` every second.

## Desired behavior

`SnapshotService.Get(ctx)` returns SnapshotDTO. On DB open failure, log and start with DB-failed snapshot. DB closed after `app.Run`. Window title MACROX RouteDeck.

## Dependencies

- RD-015 DONE

## Scope

- `internal/adapter/inbound/wails` DTO and service
- `main.go` wiring; delete `greetservice.go`
- Regenerate bindings

## Out of scope

- Frontend shell screens, tray, product events

- MUST NOT invent Wails APIs; check vendor first
