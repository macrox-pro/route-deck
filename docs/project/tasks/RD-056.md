# RD-056: Dock attention badge

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Show Dock badge `!` when a profile is applied and ProtectionState is not Active; clear otherwise; vendor dock service; table-test badgeFor.

## Context

ADR-0014. `pkg/services/dock` exists in Wails v3.0.0 module but is not vendored.

## Desired behavior

- badgeFor(snapshot) pure helper + tests
- Attach dock service; update on protection/snapshot events
- Unsupported platform: Debug once, continue
- go mod vendor refreshes dock package

## Scope

- `internal/adapter/inbound/dock`, main wiring, vendor refresh
- STATUS / BACKLOG / HANDOFF

## Out of scope

- Notifications; HideAppIcon; agent commit

## Acceptance criteria

- [ ] badgeFor table tests: no applied → empty; Active → empty; applied+Degraded/Failed/Unprotected → `!`
- [ ] `go mod vendor` includes dock
- [ ] `go test` for dock package PASS; `golangci-lint run ./...` PASS

## Constraints

- MUST follow AGENTS.md and ADR-0014 Closed rules
- Badge text only `!`
- MUST NOT invent dock APIs; verify in module/vendor
- MUST NOT `git commit`

## Verification

- command: `go test ./internal/adapter/inbound/dock/`
- command: `golangci-lint run ./...`
