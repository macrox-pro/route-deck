# RD-010: Profile and ValidateProxyRefs

Status: DONE
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Add Profile and ApplicationPolicy and reject unresolved proxy ids without rewriting actions to Direct.

## Context

Depends on RD-009. Closed signature and test names live in this task Scope.

## Current behavior

No Profile type and no proxy-ref validation in Go.

## Desired behavior

`ValidateProxyRefs` returns `ErrUnresolvedProxy` for a missing proxy id on a Proxy action, leaves Action unchanged, and does not treat Direct as a proxy ref.

## Dependencies

- RD-009 DONE before this becomes READY

## Scope

Files: `internal/domain/errors.go` (sentinels only), `internal/domain/profile.go`, `internal/domain/profile_test.go`.

Closed fields:

- `ApplicationPolicy`: `ProcessID ProcessIdentityID`, `Action RoutingAction`. Nothing else. Plain struct with no constructor.
- `Profile`: `ID ProfileID`, `Name string`, `Policies []ApplicationPolicy`. Name empty is `ErrEmptyName`.

Constructor (owner, 2026-11-17):

- Only `NewProfile(id ProfileID, name string, policies []ApplicationPolicy) (Profile, error)`.
- Error only when `name == ""` (`ErrEmptyName`, no trim). Empty ID, empty `policies`, and policy contents are not checked.
- `ValidateProxyRefs` is not called from the constructor. On error return the zero value.
- `ApplicationPolicy` is a plain struct with no constructor.

```go
func ValidateProxyRefs(profile Profile, known []ProxyID) error
```

Returns `ErrUnresolvedProxy` when a `Proxy` action's id is not in `known`. Does not change `Action`. Does not accept a process interface. Lives in `internal/domain`, not in the port package.

Tests, names fixed:

- `TestValidateProxyRefs/known_id`
- `TestValidateProxyRefs/missing_id` wants `errors.Is` `ErrUnresolvedProxy` and the same `Action` as the input
- `TestValidateProxyRefs/direct_is_not_a_proxy_ref` a `Direct` action with an empty proxy id is not `ErrUnresolvedProxy`

New sentinels in `errors.go`: `ErrUnresolvedProxy`, `ErrEmptyName`. Do not change the package comment or any other text in that file.

Later loop: struct and constructor, then `ValidateProxyRefs`, then the three tests, then lint and `go test ./internal/domain/...`.
