# RD-014: SQLite catalog for domain aggregates

Status: DONE
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Persist Application, ProcessIdentity, ProxyEndpoint (no password), and Profile in SQLite via GORM, with ports List/Save/Get and round-trip tests.

## Context

Phase 2 ports exist. Persistence starts after domain ports (roadmap Phase 3 / E02). Folds RD-006 smoke into this task.

## Current behavior

No GORM dependency. No sqlite adapter. Ports only have `ProxyStore.Get` and `SecretStore.Load`.

## Desired behavior

SQLite file opens with WAL, foreign keys, busy_timeout 5000, synchronous NORMAL, one connection. Five tables AutoMigrate. Store implements the four ports. Zero RoutingAction returns ErrUnsetAction and is never stored as Direct.

## Dependencies

- RD-012 DONE
- Owner accepted this stage plan

## Scope

- `go get` gorm.io/gorm and gorm.io/driver/sqlite; `go mod vendor`
- `ErrUnsetAction` and `RoutingAction.IsSet()`
- Extend ports: ProxyStore List/Save; ApplicationStore, ProcessIdentityStore, ProfileStore
- Package `internal/adapter/outbound/persistence/sqlite`
- Mark RD-006 DONE after smoke passes

## Out of scope

- Keychain adapter, ProxyBridge, Wails service, frontend
- Events, settings tables, password column

## Acceptance criteria

- [x] `go.mod` requires gorm.io/gorm and gorm.io/driver/sqlite; vendor refreshed
- [x] Five tables; no password column
- [x] Round-trip tests PASS; missing Get is ErrNotFound; unset action not stored as Direct
- [x] `golangci-lint run ./...` PASS

## Constraints

- MUST NOT import GORM from domain or application
- MUST NOT return `*gorm.DB` outward
- MUST NOT store secrets in SQLite
- MUST NOT rewrite unresolved proxy to Direct
