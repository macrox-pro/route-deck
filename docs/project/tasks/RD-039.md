# RD-039: HTTP CONNECT proxy health

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Probe HTTP proxies with CONNECT and report `AuthenticationFailed` on 407 without inventing UDP health words.

## Context

ADR-0012. ADR-0008 left HTTP as TCP-only. Owner chose always-CONNECT with optional Basic auth.

## Current behavior

`proxyhealth.Checker` returns `Available` for HTTP after TCP connect. `TestCheckHTTPAvailable` accepts a silent server.

## Desired behavior

HTTP branch sends `CONNECT example.com:443`, maps 200→Available, 407→AuthenticationFailed, other/errors→Unavailable, all with nil error. Rewrite HTTP tests.

## Dependencies

- ADR-0012 Accepted
- Non-blocking: RD-033 / RD-037 / RD-038 / RD-007 REVIEW

## Scope

- HTTP CONNECT in `proxyhealth.Checker`
- Table-driven tests; rewrite `TestCheckHTTPAvailable`
- ADR-0012; pointer in ADR-0008; STATUS/BACKLOG/HANDOFF

## Out of scope

- Auto-Apply
- Keychain load-error handling changes
- Digest auth / second CONNECT after 407
- Frontend changes
