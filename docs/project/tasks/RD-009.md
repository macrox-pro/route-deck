# RD-009: Application, ProcessIdentity, ProxyEndpoint

Status: TODO
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Add the three domain structs named in the domain model, with no password field and no UDPLimitation home.

## Context

Depends on RD-008. Closed fields live in this task Scope.

## Current behavior

No Application, ProcessIdentity, or ProxyEndpoint types in Go.

## Desired behavior

The three structs exist with only the closed fields below. `MatchableNames` returns bundle id and executable name only. Proxy port is 1–65535. Empty host is an error. New ProxyEndpoint uses `SendDomain: true`.

## Dependencies

- RD-008 DONE before this becomes READY

## Scope

Files:

- `internal/domain/application.go`
- `internal/domain/process_identity.go`
- `internal/domain/proxy_endpoint.go`
- matching `*_test.go`

Closed fields:

- `Application`: `ID ApplicationID`, `DisplayName string`, `BundleID string`, `IconRef string`. `IconRef` is a string. Empty is allowed. No path type, no image type.
- `ProcessIdentity`: `ID ProcessIdentityID`, `ApplicationID`, `BundleID string`, `ExecutableName string`, `Path string`, `SigningHint string`. `SigningHint` is a string, not an enum. `MatchableNames() []string` returns bundle id and executable name, skipping empty strings, skipping any string that contains `/`. Path and `SigningHint` are not returned.
- `ProxyEndpoint`: `ID ProxyID`, `Name string`, `Kind ProxyKind`, `Host string`, `Port int`, `KeychainRef KeychainRef`, `SendDomain bool`. New value uses `SendDomain: true` because the profile contract says a missing `sendDomain` means true. Port outside 1–65535 is `ErrInvalidPort`. Empty host is `ErrEmptyHost`.

New sentinels in `errors.go`: `ErrInvalidPort`, `ErrEmptyHost`. No others.

Later loop, in order: `application.go` and test, `process_identity.go` and test (include one `/` name and one path that must not appear in `MatchableNames`), `proxy_endpoint.go` and test (port 0, port 65536, empty host, default `SendDomain`), lint, `go test ./internal/domain/...`.

## Out of scope

- Profile, ValidateProxyRefs, DeriveProtection
- Username, Password, UDPLimitation field
- Adapters

## Acceptance criteria

- [ ] Closed fields only; no username, password, protocol, or UDPLimitation field
- [ ] `MatchableNames` skips empty strings and strings containing `/`; path and SigningHint are absent from the result
- [ ] Port 0 and 65536 return `ErrInvalidPort`; empty host returns `ErrEmptyHost`; new value has `SendDomain: true`
- [ ] `go test ./internal/domain/...` PASS
- [ ] `golangci-lint run ./...` PASS
