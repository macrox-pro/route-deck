# RD-060: Auto Apply at startup

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Opt-out Auto Apply on launch (SQLite, default ON), independent of Launch at Login, calling existing ProtectionService.Apply once at startup when closed gates pass (ADR-0015).

## Context

Owner closed: allow Auto Apply; default ON; independent of Launch at Login. ADR-0015 Accepted supersedes ADR-0008/0010 no-auto-apply ban.

## Current behavior

Launch at Login only registers OS Autostart. No Apply at process start. No `autoApply` setting.

## Desired behavior

- SQLite `auto_apply` default true; Settings toggle
- Startup one-shot Apply when gates pass (verbatim ADR-0015 list)
- Quiet skip otherwise; failure uses existing operation.failed; never Direct

- Non-blocking: RD-059 REVIEW; RD-033 owner smoke
