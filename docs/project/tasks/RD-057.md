# RD-057: CI macOS package without notarization

Status: REVIEW
Priority: P2
Owner: agent
Reviewer: owner

## Goal

Add a GitHub Actions workflow that packages `RouteDeck.app` on macOS with ad-hoc codesign only (no Developer ID, no notarization).

## Context

Owner asked for CI that builds a macOS version without Signing+notarize. RD-007 intentionally left Wails package out of the PR check gate. ROADMAP phase 8 wants a reproducible macOS build with unsigned limits stated. Commands: `docs/operations/build.md`, `docs/operations/release.md`.

## Current behavior

`.github/workflows/ci.yml` runs tests, lint, and frontend build only.

## Desired behavior

`.github/workflows/build-macos.yml` runs on `workflow_dispatch`, push to `main`, and tags `v*` on `macos-14`: install Wails CLI v3.0.0, `npm ci`, `wails3 task darwin:package` with CGO and vendor mode, zip `bin/RouteDeck.app`, upload artifact. Docs state ad-hoc / unsigned limits. PR checks stay on `ci.yml`.

## Dependencies

- Non-blocking: RD-007 remains REVIEW (check gate unchanged)

## Scope

- Add `.github/workflows/build-macos.yml`
- Update `docs/operations/build.md`, `docs/operations/release.md`, ADR-0005 CI sentences
- Update STATUS, BACKLOG, HANDOFF

## Out of scope

- Developer ID, notarization, secrets for certificates
- Universal (`package:universal`) or DMG packaging in CI
- Changing `ci.yml` PR gates
- ESLint
- macOS UI / ProxyBridge smoke in CI
- GitHub Release upload automation

- [x] Job uses `macos-14`, installs `wails3@v3.0.0`, runs `wails3 task darwin:package`, uploads `RouteDeck.app.zip`
- [x] No Developer ID / notarize steps or certificate secrets
