# RD-048: Profiles app-grouped editor + Review helpers preselect

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Replace the Profiles policy editor with an Applications-style app list (icon, name, Action; helpers nested; Apply app action to helpers), and pre-check already catalogued helpers on Review helpers.

## Context

Owner (2026-11-17): (1) A — show all catalog apps with None; (2) B — helpers independent + explicit Apply app action to helpers; (3) remove flat policy rows and Add-all block. Also: Review helpers must show already-saved selection. Uncheck-delete deferred (not requested).

## Current behavior

Flat Process/Action rows + bulk Add all. Review helpers always opens with all checkboxes unchecked.

## Desired behavior

- Profile form lists every catalog app: icon, name, Action on the right (None/Proxy/Direct/Block + proxy fields)
- Confirmed helpers/sidecars nested under the app with their own Action
- Button Apply app action to helpers copies main Action (and proxy fields) onto helpers
- Save still emits per-process PolicyDTO rows (None omitted)
- Review helpers pre-selects helpers already in ProcessIdentity for that app

## Dependencies

None. Supersedes RD-047 form UX for the editor body.
