# RD-052: EditorDialogs host and dialog shell

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Add cross-platform EditorDialogs (profile/proxy/helpers windows) with AttachModal + SetEnabled, dirty RegisterHook, and frontend dialog routes outside AppShell with platform footer button order.

## Context

ADR-0014, desktop-ux.md. Inline editors stay until RD-053..055 move forms.

## Desired behavior

- EditorDialogsService: OpenProfile, OpenProxy, OpenHelpers, SetDirty, Close
- One window per kind; native frame; parent SetEnabled false; AttachModal; dirty discard Question
- OnWindowEvent WindowClosing re-enables parent (hook Cancel skips listeners)
- Hash routes `/#/dialog/...` outside AppShell; dialog-footer; tray Open focuses open editor

## Scope

- `internal/adapter/inbound/wails` EditorDialogs*
- `main.go` wiring
- `frontend/src/main.tsx`, dialog shell/footer components
- tray show path; STATUS / BACKLOG / HANDOFF

## Out of scope

- Full profile/proxy/helpers form bodies (RD-053..055)
- Frameless; blocking bindings; agent commit

## Acceptance criteria

- [ ] Open/Show/Focus reuse; Close cleans up; parent re-enabled
- [ ] Dirty Cancel keeps window; Confirm closes
- [ ] Dialog routes render without AppShell chrome
- [ ] Footer Cancel/Save order by platform
- [ ] `golangci-lint run ./...` PASS; `cd frontend && npm run build` PASS

## Constraints

- MUST follow AGENTS.md and ADR-0014 Closed rules
- Only cross-platform Wails APIs verified in vendor/
- MUST NOT Frameless; MUST NOT block binding on channel
- MUST NOT `git commit`

## Verification

- command: `golangci-lint run ./...`
- command: `cd frontend && npm run build`
