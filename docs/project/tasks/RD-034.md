# RD-034: Installed application browse list

Status: DONE
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Browse installed macOS applications (with icons) behind ports, and add a chosen app to the catalog without auto-import.

## Context

ADR-0009. Existing picker and helper confirmation from ADR-0008 / RD-022 / RD-031.

## Current behavior

Applications page lists only the SQLite catalog. Intake is PickAndAdd only.

## Desired behavior

ListInstalled returns indexed + three-root apps with `inCatalog`. Icon returns 32px PNG. AddFromPath reuses AddApplicationFromPath. UI shows a filterable installed list with icons; Add then helper confirm. Nested helpers are not in the browse list.
