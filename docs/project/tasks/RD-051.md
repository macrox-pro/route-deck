# RD-051: HelperGroupDTO, sync Confirm, rule collapse

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Ship Go helper groups, sync ConfirmHelpers (add/remove/ErrReferenced), path refresh on re-confirm, BuildRulePlan collapse of shared bundle ids, ErrConflictingMatch, pendingCount, and catalog.changed.

## Context

ADR-0014. afb231c already stores one identity per bundle id and groups in TS. Uncheck still does not remove. Compile still emits one rule per identity.

## Desired behavior

- Catalog.HelperGroups + HelperGroupDTO (ExecutableNames from inspect)
- Confirm sync: unchecked deletes all identities for that bundle id; ErrReferenced if any profile references any; re-confirm refreshes path/exec
- BuildRulePlan collapses shared bundle id + same action to one rule (bundle id only); ErrConflictingMatch on different actions
- pendingCount; event catalog.changed; bindings regenerated

## Scope

- domain, catalog, ruleplan, wails applications/profiles DTOs, bindings
- tests; STATUS / BACKLOG / HANDOFF

## Out of scope

- Dialog windows UI; Dock; agent commit

## Acceptance criteria

- [ ] Four stored rows with same helper bundle id compile to one rule (test)
- [ ] Conflicting actions return ErrConflictingMatch (test)
- [ ] Uncheck removes; referenced returns ErrReferenced (test)
- [ ] Re-confirm refreshes path; no duplicate insert
- [ ] HelperGroupDTO + pendingCount + catalog.changed
- [ ] `go test ./internal/...` PASS; `golangci-lint run ./...` PASS

## Constraints

- MUST follow AGENTS.md and ADR-0014 Closed rules
- One ProcessIdentity per bundle id; no path in processNames
- MUST NOT map ErrReferenced/ErrConflictingMatch to Direct
- MUST NOT migrate SQLite duplicate rows
- MUST NOT `git commit`

- command: `go test ./internal/...`
- command: `golangci-lint run ./...`
