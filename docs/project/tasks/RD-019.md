# RD-019: Domain and ports for the vertical slice

Status: TODO
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Extend domain policies and application ports so the slice can persist settings, delete with reference checks, inspect apps, and store secrets without inventing APIs later.

## Context

ADR-0008. Existing ports cover List/Save/Get and SecretStore.Load only.

## Current behavior

`ApplicationPolicy` has ProcessID + Action only. No Username on ProxyEndpoint. No Delete, SettingsStore, ApplicationInspector, or SecretStore Save/Delete.

## Desired behavior

Policy gains ProtocolScope and UDPLimitation (unset scope on Proxy rejected). ProxyEndpoint gains Username. Sentinels: referenced entity, duplicate bundle id, duplicate profile name. Ports: Delete on stores, SettingsStore (desired profile, bridge path, debug logging), SecretStore Save/Delete, ApplicationInspector with a neutral result. domain-model.md updated.
