# RD-008: Domain value types

Status: DONE
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Add `internal/domain` value types and parsers with no aggregates and no protection derivation.

## Context

Phase 2 starts after Phase 0 and Phase 1. Closed lists live in this task file Scope. `internal/` does not exist yet.

## Current behavior

No `internal/domain` package. Domain names exist only in CONCEPTION and `docs/architecture/domain-model.md`.

## Desired behavior

`internal/domain` holds the closed type list below. Empty ids and unknown state tokens are typed errors. An unknown state token does not parse as `Active`.

## Dependencies

- RD-005 DONE (non-blocking for types; contracts already frozen)
- No blocking open ADR

## Scope

Files, and only these:

- `internal/domain/errors.go` — package doc; sentinels `ErrEmptyID`, `ErrUnknownState`, `ErrUnknownProxyKind`. No other sentinel in this task.
- `internal/domain/id.go` — `ProxyID`, `ApplicationID`, `ProcessIdentityID`, `ProfileID`, `KeychainRef`. Each is a string. Empty is `ErrEmptyID`. Parsers: `ParseProxyID`, `ParseApplicationID`, `ParseProcessIdentityID`, `ParseProfileID`, `ParseKeychainRef`.
- `internal/domain/state.go` — `BridgeState`, `ProxyHealth`, `ProtectionState`, with the spellings in CONCEPTION and no others. Constant names carry the type prefix (`BridgeStateUnknown`, `ProxyHealthUnknown`, `ProtectionStateUnknown`). Parsers: `ParseBridgeState`, `ParseProxyHealth`, `ParseProtectionState`. Matching is exact and case-sensitive. Parse of an unknown token returns `ErrUnknownState` and does not return `Active`.
- `internal/domain/policy.go` — `ProxyKind` (`socks5`, `http`) with `ParseProxyKind` (rejected kind returns `ErrUnknownProxyKind`); `ProtocolScope` (`TCP`, `UDP`, `BOTH`) and `UDPLimitation` (`Absent`, `DirectUDP`) as constants only, no parsers; opaque `RoutingAction` with unexported fields `proxyID`, `direct`, `block` (no internal kind type). Constructors: `ProxyAction(ProxyID) (RoutingAction, error)` (empty id returns `ErrEmptyID`), `DirectAction()`, `BlockAction()`. Methods: `IsDirect()`, `IsBlock()`, `ProxyID() (ProxyID, bool)`. Zero value is not Direct. No string form.
- `internal/domain/id_test.go`, `state_test.go`, `policy_test.go` — table tests in package `domain_test`. One empty value per id type. One unknown token per state enum. One rejected proxy kind. Every CONCEPTION state token and both proxy kinds parse. Empty string and case variant `active` return `ErrUnknownState`. `ProxyAction("")` returns `ErrEmptyID`; zero `RoutingAction` is not Direct.

Later loop, in order: write `errors.go`, then `id.go` and its test, then `state.go` and its test, then `policy.go` and its test, then `go test ./internal/domain/...`, then `golangci-lint run ./...`.

### Owner decisions (closed 2026-11-17)

1. Rejected `ProxyKind` returns `ErrUnknownProxyKind` (third sentinel).
2. Function set as listed above; `ProtocolScope` and `UDPLimitation` have no parsers.
3. `RoutingAction` is opaque with unexported `proxyID`/`direct`/`block` fields (no second policy enum).

## Constraints

### Stop list

An agent that hits one of these stops and asks the owner. It does not pick a plausible option.

- A field, method, error name, enum value, file, or package that this task Scope does not name
- A home for `UDPLimitation` or `ProtocolScope` (the value types exist; no struct owns them yet)
- A port method other than `ProxyStore.Get` and `SecretStore.Load`
- A second policy enum besides `RoutingAction`
- A `ProtectionState` word other than the 14 steps in RD-011 Scope
- Parsing ProxyBridge JSON, starting a process, opening SQLite, or calling Keychain
- `createdAt`, `updatedAt`, UUID, integer ids, username, password, icon file format, signature status enum
- A helper used once, a `Util` / `Helper` / `Manager` name, an empty package for later

### MUST NOT

- Subpackages
- A `Policy` enum next to `RoutingAction`
- An internal `routingKind` type (use unexported bool fields instead)
- A field that stores `UDPLimitation`
- Port validation (that is RD-009)
- Profile types
- `git commit` (owner commits)
