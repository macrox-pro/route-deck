# RD-037: Launch at Login

Status: REVIEW
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Settings exposes Launch at Login; toggling registers or removes OS login launch via Wails Autostart without auto-Apply.

## Context

ADR-0010. Wails `app.Autostart` (`Enable` / `Disable` / `IsEnabled`) verified in vendor. ADR-0008: no auto-Apply at startup.

## Current behavior

No Launch at Login control.

## Desired behavior

`SettingsDTO.launchAtLogin` from OS `IsEnabled`. `SetLaunchAtLogin(enabled)` calls Enable/Disable. Settings UI Toggle. Login does not Apply. Smoke notes: bundled may use SMAppService; `wails3 task run` may use LaunchAgent.

## Dependencies

- RD-036 DONE (or non-blocking if tray shell already present; prefer after RD-036)
- ADR-0010 Accepted
