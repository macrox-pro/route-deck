# RD-035: Tray resident + Open / Quit dialog shell

Status: DONE
Priority: P0
Owner: agent
Reviewer: owner

## Goal

Keep RouteDeck running when the window closes: menu-bar tray, Open restores the window, every Quit path shows a Question dialog.

## Context

ADR-0010. CONCEPTION: window closed keeps the app running; Quit warns and stops the managed CLI. Current `main.go` still sets `ApplicationShouldTerminateAfterLastWindowClosed: true`.

## Current behavior

Closing the last window terminates the process. No system tray.

## Desired behavior

`ShouldTerminate=false`. Close Cancels destroy and Hides. Dock icon stays. Tray template icon. Menu skeleton with Status, Open, Stop (disabled until RD-036 live enable), Quit. Tray click and Dock click Show the window. Quit always opens a Question dialog (Cancel stays; Confirm quits). No silent quit.
