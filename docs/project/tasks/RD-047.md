# RD-047: Profiles form layout + add-all by application

Status: REVIEW
Priority: P1
Owner: agent
Reviewer: owner

## Goal

Make the Profiles create/edit form readable, and let the owner add every saved process under an application in one action while still editing one process at a time.

## Context

Owner answers (2026-11-17): Layout single-column with min-w-0; selection model C (per-process + bulk-by-application); append missing processIds only; silent no-op on duplicates; only catalogued ProcessIdentity rows (no auto-ConfirmHelpers).

## Current behavior

Policy cards use `md:grid-cols-2`; long process labels stretch the form. Process picker is flat; ChatGPT + helpers require many manual rows.

## Desired behavior

- Single-column policy cards; no horizontal overflow at typical widths
- Per-process rows unchanged in meaning
- Add all for application: one policy per missing process with shared Action (and proxy fields when Proxy)
- Existing processIds left alone; zero missing → silent no-op
