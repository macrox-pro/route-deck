# RD-058: Link-time app version and commit in Settings / sidebar

Status: REVIEW
Priority: P2
Owner: agent
Reviewer: owner

## Goal

Inject git tag version and short commit into the macOS build so Settings shows About details and the sidebar badge shows the short label (`v1.2.3` or `dev`).

## Context

Owner decisions: conventional `vMAJOR.MINOR.PATCH` tags; untagged → `dev`; short commit (7); sidebar short label only; Settings About for version + commit. Builds on RD-057 `build-macos` workflow.

## Current behavior

Hardcoded `0.1.0` in `build/config.yml` / Info.plist and frontend `APP_VERSION`. Settings shows ProxyBridge version only.

## Desired behavior

- `internal/buildmeta` with defaults `Version=dev`, empty `Commit`
- CI / `darwin:package APP_VERSION=… APP_COMMIT=…` inject via `-ldflags -X` and stamp Info.plist
- Tag `v1.2.3` → version `1.2.3`, label `v1.2.3`; else `dev`
- SettingsDTO carries appVersion / appVersionLabel / appCommit; Settings About + sidebar badge
